What DADA is: a prompt-level **agent skill** (installed with `npx skills add AnEntrypoint/dada -s dada` or by copying skills/dada). It is not a CLI, MCP server, HTTP API or importable library. An LLM agent loads SKILL.md and runs a non-linear traversal of the anchor graph with an independent critic panel (Autonomous or Adaptive mode) until stop conditions S1-S5 hold, writing five artifacts (Traversal Plan, Decision Records, Panel Reports, Anchor Ledger, Compliance Check) to DESIGN-LOG.md. It covers identity, posters, books, editorial, motion, type, imagery, data graphics and interfaces, so it applies to website design. tools/measure.py and pixcontrast.py measure DADA's own web/ page in headless Chromium (python3 + /usr/bin/chromium); they are project tooling, not a general design API. The JARVIS kernel has no inference, so it never runs the loop itself.

License: no LICENSE file in the fork or upstream at this revision; GitHub reports none. Reuse is not cleared, so the policy is pin + fetch only. Updates: `npm run upstream -- update dada` (see docs/UPSTREAMS.md).
